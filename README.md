# Tech Salary Analysis

End-to-end data analysis of tech salaries using the Stack Overflow Developer Survey 2025.

> Work in progress. Full write-up coming soon.

## Project structure

- `data/`       raw and processed data (not tracked, see `data/README.md`)
- `notebooks/`  analysis notebooks, numbered in execution order
- `src/`        reusable helper code
- `reports/`    figures used in the write-up
